# Manuscript repository statement and software citations

## Recommended code and data availability statement

The computational workflow and supporting materials are publicly documented in
two versioned repositories. AISKG Section 1
(https://github.com/romenmeitei/AISKG_01_Framework) contains the literature
retrieval, frozen corpus snapshot, topic-curation, and ontology-guided semantic
extraction workflow. AISKG Section 2
(https://github.com/romenmeitei/AISKG_02_Framework) contains the deterministic
knowledge-graph, temporal, pathway, expert-validation, benchmarking,
co-occurrence, and research-representation analyses. Both repositories include
Google Colab notebooks, command-line implementations, SHA-256 manifests,
reference outputs, and test evidence. The frozen snapshot reproduces the
published results; optional live retrieval may yield different records because
bibliographic databases and indexing change over time. Bibliographic fields
obtained from licensed services remain subject to provider terms. Where public
redistribution is restricted, authorized users should retrieve the records
using the released queries and their own database access, or request the frozen
snapshot through the stated controlled-access route.
